**공개 데모** → https://kittycong.github.io/eopmu-bunjang/

> 공개본은 **성명 마스킹(김O원) · 연락처 삭제 · 캡처 미포함** 처리된 샘플이다.
> 실명 원본(`tasks.json`)과 인계 문서, 화면 캡처는 저장소에 올리지 않는다(`.gitignore`).

## 업무 한 건에 담기는 것

```
업무명 · 분야 · 주기 · 기한 · 사용 시스템 · 진행 상태 · 인수인계 구분/상대방
├ 1. 업무 개요
├ 2. 처리 절차          체크박스
├ 3. 자주 발생하는 이슈
├ 4. 관련 문서 파일명
├ 5. 접근 권한 · 폴더 위치
├ 6. 업무 캡처          Ctrl+V 붙여넣기
├ 7. 다음 액션
└   작업 기록           날짜별 누적
```

처음 해보는 업무는 **작업 기록**에 남기고, 정리되면 **처리 절차**로 올린다. 인계 문서는 이 절차를 그대로 출력한다.

## 쓰는 법

`docs/index.html` 을 브라우저로 열면 끝. 편집 내용은 브라우저(localStorage)에 저장된다.
여러 기기에서 쓰려면 `JSON 내보내기` → 다른 기기에서 `가져오기`.

**백업** — 저장할 때마다 «바뀌기 직전» 상태가 자동으로 쌓인다(최근 8개).
`백업 · 복원` 에서 시점을 골라 되돌릴 수 있고, 되돌리기 직전 상태도 남으므로 복원 자체를 취소할 수 있다.
브라우저 데이터를 지우면 백업도 함께 사라지므로, 중요한 시점은 `파일로 내려받기` 로 보관할 것.

**추출 스크립트는 덮어쓰지 않는다** — `extract_events.py` 는 id 기준으로 병합한다.
앱에서 추가한 일정·교육 수료 기록·인계 이력은 재실행해도 남는다.

## 로컬에서 빌드

```bash
python extract_people.py     # 엑셀 -> 직원 명단
python extract_events.py     # 엑셀 -> 센터 일정 · 지침 목록 (병합: 기존 항목 보존)
python extract_events.py --refresh   # 시트 값으로 기존 항목까지 갱신
python anonymize.py          # 실명본 -> 공개 마스킹본
python build.py both         # index.html(내부) + docs/index.html(공개)
python make_handover.py 홍길동          # 인계 문서 docx + html
python make_handover.py 홍길동 --type in # 인수 체크리스트
```

`python -m http.server` 같은 것도 필요 없다. `template.html` 이 화면, `tasks.json` 이 데이터, `build.py` 가 둘을 합쳐 단일 파일로 만든다.

## 파일

| 파일 | 역할 |
|---|---|
| `template.html` | 앱 본체 (HTML·CSS·JS 한 파일) |
| `tasks.public.json` | 공개용 데이터 (마스킹본) |
| `build.py` | 템플릿 + 데이터 → 단일 HTML |
| `anonymize.py` | 성명 마스킹 · 연락처 제거 · 캡처 제거 |
| `extract_people.py` / `extract_events.py` | 업무분장 엑셀에서 명단·일정 추출 |
| `make_handover.py` | 특정 담당자 인수인계서 생성 (docx / html) |

## 개인정보 취급

- 공개 저장소에는 **마스킹본만** 올린다. `tasks.json`, `인계자료/`, `캡처/`, `index.html` 은 `.gitignore` 처리.
- `anonymize.py` 는 마스킹 후 원본 성명·연락처가 남아 있으면 **빌드를 실패시킨다.**
- 화면 캡처에는 개인정보가 찍힐 수 있어 공개본에서 통째로 제거한다.
